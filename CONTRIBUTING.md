# Contributing

Run `node --test test/*.test.cjs` and serve `site/` locally. There is no install or build step.

Useful contributions include keyboard and touch controls, language support, accessibility and small camp additions. Describe the behavior you changed and how you checked it. Keep new assets original or include their license.

Use fictional tasks in issues, screenshots and pull requests. Never attach a browser backup containing personal tasks. This project intentionally has no task-upload API or analytics; discuss any change to that boundary before implementing it.

The scene and task journal should both remain usable: a player should not have to move a character to manage a task. Keep pause/resume and once-only rewards intact.
