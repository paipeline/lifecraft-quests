# Lifecraft Quests

After completing substantive work or receiving a concrete new assignment in a daily task chat, sync that change before ending the turn. Skip turns with no task or progress change.

1. Use the user's current Lifecraft tab and browser profile. The [hosted app](https://paipeline.github.io/lifecraft-quests/) and localhost, as well as different profiles, store separate quests. If you cannot access or identify the intended save, report the pending update so it can be retried when the save is available.
2. Look for the existing quest for the same deliverable across dates, including completed quests. Update it in place. If there is no match, create one in **任务日志** (Quest Journal) using **新建任务** (New Task). Use the date agreed in the chat or the camp's current date. Leave both time fields blank if the task has no assigned time.
3. In **备注** (Notes), keep the quest's existing information and record the verified outcome, any remaining blocker, the next action and a link to the deliverable if available. Preserve existing dates and times unless the user changed them. Check **已完成** (Completed) only when this quest's stated outcome is done. A draft, a request sent or a third-party decision pending may each represent a different outcome. Progress sync does not use the reward or focus timer controls.
4. Use **保存待办** (Save Task), then verify the title, note and status in the same save. If an attempt is interrupted, check for the quest before retrying to avoid duplicates.
